### 📄 Publications

**[On the Impact of the RPL Decreased Rank Attack on 6TiSCH Networks](https://ieeexplore.ieee.org/document/10539163)** *(Carleton University, Next Generation Networks Lab)*

A study of how the RPL decreased rank attack affects 6TiSCH networks, which are built on the Time Slotted Channel Hopping (TSCH) mode of IEEE 802.15.4-2015 and use RPL for multi-hop IPv6 routing. I implemented it on Contiki-NG, an operating system for constrained wireless embedded devices, writing in C with Python and Bash scripting.

*Published at IEEE DRCN 2024 (20th International Conference on the Design of Reliable Communication Networks), Montreal, pp. 70–75.* · [IEEE Xplore](https://ieeexplore.ieee.org/document/10539163)
> M. Mahyoub, **S. Hossain** and A. Matrawy, "On the Impact of the RPL Decreased Rank Attack on 6TiSCH Networks," *2024 20th International Conference on the Design of Reliable Communication Networks (DRCN)*, Montreal, QC, Canada, 2024, pp. 70–75, doi: 10.1109/DRCN60692.2024.10539163.

**[Application of Machine Learning in Credit Risk Assessment: A Prelude to Smart Banking](https://ieeexplore.ieee.org/document/8929527)** *(Thesis)*

A machine learning system that predicts whether a person can repay a loan, which helps lenders decide whether to approve it.

*Published in the proceedings of IEEE TENCON 2019 (IEEE Region 10 Conference), pp. 2023–2028.* · [IEEE Xplore](https://ieeexplore.ieee.org/document/8929527)
> S. Z. H. Shoumo, M. I. M. Dhruba, **S. Hossain**, N. H. Ghani, H. Arif and S. Islam, "Application of Machine Learning in Credit Risk Assessment: A Prelude to Smart Banking," *TENCON 2019 – 2019 IEEE Region 10 Conference*, Kochi, India, 2019, pp. 2023–2028, doi: 10.1109/TENCON.2019.8929527.

**[IoT Based Patient Monitoring System Using ECG Sensor](https://ieeexplore.ieee.org/document/8644065)**

Continuously monitors a patient's condition and saves the readings to a cloud server for later reference and remote viewing. It responds automatically to the readings and includes an emergency push button and a camera that streams live on request through a web page built for the project.

*Published at the 2019 International Conference on Robotics, Electrical and Signal Processing Techniques (ICREST), Dhaka, pp. 378–382.* · [IEEE Xplore](https://ieeexplore.ieee.org/document/8644065)
> A. Rahman, T. Rahman, N. H. Ghani, **S. Hossain** and J. Uddin, "IoT Based Patient Monitoring System Using ECG Sensor," *2019 International Conference on Robotics, Electrical and Signal Processing Techniques (ICREST)*, Dhaka, Bangladesh, 2019, pp. 378–382, doi: 10.1109/ICREST.2019.8644065.
