### 📄 Publications

**1. [On the Impact of the RPL Decreased Rank Attack on 6TiSCH Networks](https://ieeexplore.ieee.org/document/10539163)**
<br>IEEE DRCN 2024 · Montreal, Canada · Carleton University, Next Generation Networks Lab

Studied how the RPL decreased rank attack disrupts 6TiSCH networks, which run on the TSCH mode of IEEE 802.15.4-2015 and use RPL for multi-hop IPv6 routing. Implemented on Contiki-NG in C, with Python and Bash scripting.

<details>
<summary>Citation</summary>

M. Mahyoub, **S. Hossain** and A. Matrawy, "On the Impact of the RPL Decreased Rank Attack on 6TiSCH Networks," *2024 20th International Conference on the Design of Reliable Communication Networks (DRCN)*, Montreal, QC, Canada, 2024, pp. 70–75, doi: 10.1109/DRCN60692.2024.10539163.

</details>
